# L'Estetique · Bellezza e Benessere di Paola Parisio

Sito one-page dello studio estetico a San Giorgio del Sannio (BN).

- `index.html` — tutto il sito (stili, script e immagini sono inclusi nel file)
- `fonts/` — caratteri ospitati in locale (licenza SIL OFL, vedi `fonts/OFL-LICENSE.txt`)

Pubblicato con GitHub Pages: ogni modifica al ramo `main` va online in automatico.
